# Nexis Platform

Nexis is a high-throughput social platform backend designed to demonstrate production-grade .NET system architecture.

## Tech Stack
- ASP.NET Core
- PostgreSQL, MongoDB
- Redis
- Kafka
- Docker

## Goals
- 2000 RPS sustained throughput
- Horizontal scalability
- Fault-tolerant event processing

## Architecture
The system is implemented as a modular monolith following DDD principles with a planned migration path to microservices.

Detailed architecture and design decisions are available in the /docs directory.
